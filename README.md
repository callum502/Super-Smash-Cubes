A C++ physics based game made for a uni project using a barebones game development framework.

The goal was to make a game using a 2D physics engine. I decided to make physics a main part of the gameplay loop by 
making the objective to knock your opponent out of the map similar to the game Super Smash Bros but with the "programmer art" of 3d cubes for players, 
hence the name Super Smash Cubes.

The game features various physics based mechanics the player can use to knock their opponent out of the map such as dashing, shooting, shielding and powerups.
